# invoice_dynamic_attachments
Invoice Dynamic Attachments

Follow below steps:
1. Create an invoice and add the product line if needed, add the section the no. of section you added into the invoice lines based on that the attachments will be added on the invoice report.
2. Now confirm the invoice.
3. Print the invoice: you can see the Attachment 1, Attachment2, 3, 4, ... and so on
4. If you click on the Attachment it will redirect to that attachment(as for now we have added the static data on the plan text file)
5. We make sure that only the admin user can see the attachment field.
